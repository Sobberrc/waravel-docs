Features

Waravel provides a complete Admin Dashboard to manage your Laravel application.

🖥️ Dashboard Center

At its heart, Waravel gives you a modern, responsive control panel powered by Tailwind CSS.

📄 Page Management

A full CMS living inside your app.

  • WYSIWYG Editor: Write content with a rich text editor.
  • Hierarchies: Infinite nesting of parent/child pages.
  • Status Workflow: Draft -> Pending -> Published.
  • SEO Controls: Custom titles, meta descriptions, and OpenGraph settings per page.

🖼️ Media Library

A unified home for your files.

  • Drag & Drop Upload: Bulk upload images, PDFs, and videos.
  • Smart Organization: Files are auto-sorted into Uploads/Year/Month folders.
  • Auto-Resize: Images are automatically optimized into Thumbnail, Medium, and Large variants.

⚙️ Settings Module

Global configuration without touching code.

  • General: Site title, tagline, and homepage settings.
  • Appearance: Choose default layouts (Full Width, Sidebar, etc).
  • Users: Manage admin access separate from your app users.
  • Maintenance: System health tools.
    • Publishing: Extract package files (Config, Views, Assets) to your application to customize them.
    • Unpublishing (Reset): Delete your custom copies and revert to the factory defaults. Warning: This deletes your changes.
  • Update Center: One-click system updates and database migrations.

🏷️ Content Organization

  • Tags: Categorize content with a robust tagging system.
  • Widgets: Manage dynamic content areas (Sidebars, Footers, Headers) with drag-and-drop ordering.

🛠️ Technical Powers

Beyond the dashboard, Waravel works hard in the background.

🛣️ Smart Fallback Router

Waravel listens for 404s. If a user visits a URL that isn't in your routes/web.php, Waravel checks if a CMS page exists.

  • No Conflicts: Your code always takes priority.
  • Zero Config: Create a page in the dashboard, and it's live instantly.

🎨 Template Engine

Connect your data to your design.

Add Blade files to resources/views/waravel/templates, and they appear as options in the Page Editor.

  • Read the Developer Guide for full details.
  • Great for Landing Pages vs Blog Posts vs Legal Docs.

🔌 Plugin System

The dashboard is modular. You can install plugins to add new menu items and functionality without bloating the core.

  • Page Builder: Create stunning layouts with a visual editor.
  • WordPress Importer: Migrate content seamlessly from your old site.
  • Redirect Manager: Manage 301 redirects and monitor 404 errors.
  • Contact Form: Build simple forms to collect user data.
  • AI Page Generator: Create complete pages instantly with AI.

🧠 Schema Manager

Built-in SEO structured data.

Define Article, Product, or Organization schemas directly in the editor, and Waravel handles the JSON-LD injection.

🛡️ Security First

Built to withstand modern threats.

  • Zero-Conflict Auth: Admin sessions are completely isolated from your main app users.
  • Attack Protection: Native defenses against XSS, CSRF, and SQL Injection.
  • Hardened File System: Directory traversal checks and upload validation to prevent malicious script execution.
