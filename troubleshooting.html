Troubleshooting

Encoutering issues? Here are the most common solutions.

🖼️ Images or Media 404 (Not Found)

If your uploaded images are broken or showing 404 errors:

Solution:

You likely missed the storage link step. Run this in your terminal: 

php artisan storage:link

*Note: If you are on shared hosting, you may need to manually symlink public/storage to storage/app/public via your hosting control panel.*

🔑 License Errors

If you see "Invalid License" or "Plugin not allowed":

Solution:
  1. Open your .env file.
  2. Ensure WARAVEL_LICENSE_KEY is set correctly.
  3. Clear your config cache: 
    php artisan config:clear

📦 "Package Not Found" during Installation

If composer require fails with a "Could not find package" error:

Solution:

You missed adding the repository to composer.json.

Open composer.json and ensure this block exists:

"repositories": [
    {
        "type": "composer",
        "url": "https://packages.waravel.com"
    }
]

🔐 Login Redirect Loop

If you try to login but keep getting redirected back to the login page without an error:

Solution:

Your config/auth.php might be missing the Waravel guard.

  1. Open config/auth.php.
  2. Check if 'waravel' is listed under guards.
  3. If missing, run php artisan waravel:install again, or add it manually (see config/waravel.php comments for details).
