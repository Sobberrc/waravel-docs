Waravel cPanel Setup

Video #5 Companion Commands

Paste and run these two commands in your cPanel Terminal:

Command 1: 
mv public_html main_core && ln -s main_core/public public_html && rm -f main_core/.htaccess
Command 2: 
cat << 'EOF' > main_core/public/.htaccess
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On

    # Redirect Trailing Slashes If Not A Folder...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    # Clean 301 Redirect: Strip /public from URLs
    RewriteCond %{THE_REQUEST} \s/+public/([^\s?]*) [NC]
    RewriteRule ^ /%1 [R=301,L]
    RewriteCond %{THE_REQUEST} \s/+public[\s?] [NC]
    RewriteRule ^ /? [R=301,L]

    # Handle Authorization Header
    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    # Pass through Anti-CSRF Token for Waravel API & FileGuard Security
    RewriteCond %{HTTP:X-XSRF-Token} .
    RewriteRule .* - [E=HTTP_X_XSRF_TOKEN:%{HTTP:X-XSRF-Token}]

    # Send Requests To Front Controller...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
EOF

What do these do?

Command 1: Moves your website files into a safe folder (main_core) and creates a shortcut link to your public folder so sensitive files are hidden.

Command 2: Sets up automatic redirection so visitors and old bookmarks without or with /public are instantly routed to your clean homepage.
