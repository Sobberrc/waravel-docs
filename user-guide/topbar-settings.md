# Settings (Global Configuration)

The **Settings (⚙️)** menu in the top bar allows you to manage the fundamental behavior and structural identity of your website.

---

## 1. Layout Settings

This is the most critical section for site architects. It defines the global "Skeleton" of your public pages.

### Default Layout Control
- **The Layout Picker**: Choose the primary Blade layout file that wraps your content.
- **Security & Validation**: Waravel strictly validates layout paths to prevent unauthorized file access. Only approved naming conventions (alphanumeric, dots, underscores) are allowed.

### Theme Synchronization
- **Active Theme Tracking**: When you select a layout that belongs to a specific theme (e.g., `theme::twentytwentysix.base`), Waravel intelligently updates your **Active Theme** setting to match. This ensures that your widgets and CSS skins are always perfectly aligned with your chosen layout.

---

## 2. Advanced Global Controls
- **License Synchronization**: Ensure your site is communicating correctly with the Waravel Portal to unlock premium features and updates.
- **Site Metadata**: Manage your global site name, tagline, and administrative email.
