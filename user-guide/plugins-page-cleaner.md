# Page Cleaner (Standard)

The **Page Cleaner** helps you manage database bloat and site performance by identifying and removing redundant content based on local database criteria.

---

## 1. Local Database Scanning
Identify pages using precise filters:
- **Status Filter**: Find all Drafts, Trashed items, or Published pages.
- **Minimum Age**: Set an age threshold (e.g., 30 days) to protect recently created content.
- **URL Prefix**: Focus the scan on specific URL paths (e.g., `/archive/`).
- **Date Range**: Scan for pages created within specific timeframes.

---

## 2. Automated Local Pruning
Standard users can automate their database maintenance:
- **Scheduled Tasks**: Configure the cleaner to run automatically on a **Daily**, **Weekly**, or **Monthly** basis.
- **Action Selection**: Choose whether to **Trash** the identified pages or **Permanently Delete** them.
- **Maintenance Logs**: Track all automated pruning actions directly in the dashboard.

---

## 3. Mass Actions
- **Bulk Trash**: Safely move hundreds of pages to the trash for final review.
- **Permanent Purge**: Instantly remove content to free up database resources.
