Configuration

Waravel's default configuration is robust enough for most production sites, but we expose deep control for power users.

🔑 Essential .env Settings

Variable Default Purpose
WARAVEL_ROUTE_PREFIX waravel The URL path for the dashboard (e.g. change to admin).
WARAVEL_MEDIA_DISK public Where to store uploads. Set to s3 for AWS storage.
WARAVEL_LICENSE_KEY Required for product activation.

🏗 Publishing Configs

To see all available options (including Image Driver settings and Mail configuration), publish the config files:

php artisan vendor:publish --tag=waravel-config

This will create:

  • config/waravel.php (Core settings)
  • config/waravel-image.php (Compression quality, drivers)
  • config/waravel-sitemap.php (Sitemap generation rules)
